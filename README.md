# Grade Checker

This is a web page that checks the grades of a student. The user types the name and three grades, then the page shows the average, remark, letter grade, and highest grade.

## How to run

1. Download or clone this repository.
2. Open the `index.html` file in a browser.
3. Type the student name and the three grades.
4. Click **Check Grades**.
5. Click **Clear** to start again.

## Files

- `index.html` - the page
- `style.css` - the colors and layout
- `grade.js` - the functions that compute the grades
- `app.js` - connects the page to the functions
