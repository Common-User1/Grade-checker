# Grade Checker

This is a web page that checks the grades of students. The user types the student name and the subjects with grades, then the page shows the average, remark, letter grade, and highest grade. The user can also save many students in a list.

## How to run

1. Download or clone this repository.
2. Open the `index.html` file in a browser.
3. Type the student name.
4. Type the subject names and grades. Click **Add Subject** to add more, or **X** to remove one.
5. Click **Check Grades** to see the result.
6. Click **Save Student** to add the student to the Saved Students table.
7. Click **Clear** to start again.

## Features

- Add or remove subjects
- Shows average, remark, letter grade, and highest grade
- Saves a list of students, and the list stays after refreshing the page
- Delete one student or clear the whole list
- Works on computers and phones

## Files

- `index.html` - the page
- `style.css` - the colors and layout
- `grade.js` - the functions that compute the grades
- `app.js` - connects the page to the functions and saves the students
